Features

Built for every age

A larger-control Easy mode, deeper haptics, app-aware rails, widgets, and real brand artwork make the remote approachable without losing power.

◐

Easy / larger controls

Bigger buttons, larger text, and simplified panels so the remote is friendly for all ages.

📳

Deeper haptics

Primitive-based thud/click/tick vibration patterns that feel deeper and more distinct per key.

🧩

App-aware controls

Live TV shows Guide/Options/Captions, media apps show Rewind/Play/Forward, everything else shows Recent apps/Search/Home.

📱

Home-screen widgets

2×2 and 4×2 widgets with Power, Back, Home, volume, mute and playback keys at your fingertips.

🎨

Real app icons

Real YouTube, Netflix, Hotstar, Prime Video, Spotify and Play Store artwork on every app card.

🔒

LAN-only & private

Per-install RSA client certificates, TV certificate pinning, no cloud, no account, nothing leaves your LAN.

Get started

Pair once, control forever

Every install generates its own client certificate. The TV shows a six-character code; you type it in once and the certificate is pinned.

1

Install

Build or install Xstream Remote on your Android phone.

2

Pair

Enable USB debugging on the TV, enter the six-character code shown on screen.

3

Control

Use the remote, widgets, or app shortcuts. Works over your local Wi-Fi only.

Download & build

Xstream Remote is released source-only. There is no bundled client key and no APK in GitHub releases.

Releases & source → Repository →
To install, build the APK locally with XSTREAM_STORE_PASS set (see docs/INSTALL.md), then sideload it. USB debugging must be enabled on the TV.

Privacy & safety

  • Passive capture only: no ARP spoofing, no MITM, no credential extraction.
  • No DRM or subscription bypass, no flashing/unlocking/factory reset, no package deletion.
  • Phone ADB is in scope; TV USB debugging remains out of scope.
  • TV certificate fingerprint is pinned after pairing; all control traffic is TLS over your LAN.
