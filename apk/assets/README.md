# Assets

`ui/index.html` is generated by `tools/make_ui.py` from
`web/index.template.html` and `web/sprite.svg`, and is committed so the APK can
be assembled without a UI toolchain.

**Do not add client certificates here.** v2 generates a per-install RSA identity
on the phone the first time it pairs; the APK contains no `client.pem` or
`client.key`. The only bundled asset is the local UI page.

`client.pem`, `client.key`, build outputs and keystores are gitignored. Do not
commit or share an APK that contains a private key.
