# Assets

`ui/index.html` is generated by `tools/make_ui.py` from
`web/index.template.html` and `web/sprite.svg`.

`client.pem` and `client.key` are **not** tracked. v1 needs a paired client
identity to talk to the box:

1. Pair with `remote/server.py` (see the root README).
2. Copy the per-device pair identity here as `client.pem` and `client.key`.
3. Rebuild.

v2 replaces this with in-app pairing, a per-install certificate, and a saved
device list. Do not commit or share a built v1 APK with your client key inside.
